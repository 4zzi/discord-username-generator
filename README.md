# How it works

uses tor for proxies

calculates your pc specs to determine how many proxies to use

uses proxies to send POST requests to ``https://discord.com/api/v9/users/`` to check if its taken

rotates to new proxies when you get rate limited

if you pick to save more then 1 username, it gets saved to a file

# How to use

place all these scripts inside a folder, then edit start.bat to be the location

then create a folder called tor, download tor expert bundle (that has the tor.exe thing) place it all in that tor folder

use a discord extension that gets your discord token, open start.bat and paste your token
